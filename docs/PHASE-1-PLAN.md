# Phase 1 – Repository and Application Foundation

## Scope
- Create GitHub repository `heptha06/personal-finance-analyzer`
- Establish the monorepo structure
- Prepare Spring Boot backend foundation
- Initialize Angular workspace
- Run local MySQL with Docker Compose
- Add documentation and safe Git ignore rules

## Explicitly out of scope
No AWS resources, S3 buckets, EC2 instances, RDS databases, IAM users, access keys, or cloud deployment.

## Completion checklist
- [ ] GitHub repository created
- [ ] Initial source tree pushed
- [ ] Java 21 and Maven verified
- [ ] Spring Boot starts locally
- [ ] Angular starts locally
- [ ] MySQL container starts and accepts a connection
- [ ] No sensitive data committed

## Evidence
Capture GitHub repository/tree, backend startup, frontend server, and MySQL container health.
